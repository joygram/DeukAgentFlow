# 원칙

## 단일 목표와 세 축

- 목표 = 사람·에이전트의 협업 효율 향상.
- Skill = 작업 절차·확인 기준; 과잉 가정·과잉 수정 억제.
- Persona = 대화의 일관성·상황 반응; 협업 경험 지원.
- Flow = 범위·상태·검증·인계; Role = 단계별 전문 관점.
- 효율·토큰 절감 = 제품 자체 비교 실측으로 입증할 목표.

## 정본과 경계

- 규칙 정본을 한 곳에서 관리; 클라이언트에는 포인터로 전달.
- 사용자 요청·설계·변경 범위를 기준으로 실행.
- 생성 파일 변경은 원본·생성 경로로 반영.
- 티켓 상태·인덱스는 CLI로 관리; 계획과 완료 근거 구분.
- 이전 작업·실패 근거·사용자 변경 보존.

## 검증과 표현

- 완료 = 실제 결과·검증 근거·잔여 위험을 함께 전달.
- 누락·미실행·미검증을 통과로 보고하지 않음.
- Persona는 대화 표현 담당; 기술적 사실·품질 판정은 근거 유지.
- 관련 논문 수치 = 해당 실험의 결과; 제품 자체 성능과 구분.
