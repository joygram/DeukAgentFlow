# Ticket Workflow 템플릿: phase1

## 작성 슬롯
- Scope & Approval: 범위, 요구사항, 접근법
- Plan: 단계별 실행 계획
- Analysis: 원인 분석 + 파일:라인 증거 + 가설
- Direction: 개선 방향

## 전이 조건
- 4개 섹션이 모두 채워져야 Phase 2로 이동합니다.

## 플랜 수정이 필요한 경우
- Phase 2 진입 후에는 플랜을 직접 수정할 수 없습니다.
- 스코프 확장: 새 티켓을 먼저 생성한 뒤, 현 티켓 close 시 "새 티켓 #XXX로 확장" 증거를 남깁니다.
- 플랜 재설계: 현 티켓을 close("플랜 재설계로 #XXX 신규 생성" 기록)하고 새 티켓 Phase 1부터 다시 시작합니다.
