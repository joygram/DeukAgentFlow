# Ticket Workflow Template: phase1

## Writing Slots
- Scope & Approval: scope boundary, requirement, approach
- Plan: step-by-step execution plan
- Analysis: root cause + file:line evidence + hypotheses
- Direction: improvement direction

## Transition Condition
- All 4 sections must be filled before moving to Phase 2.

## If the Plan Needs to Change
- Plans cannot be modified directly after entering Phase 2.
- Scope expansion: create the new ticket first, then close the current ticket with evidence "expanded to #XXX".
- Plan redesign: close the current ticket (record "redesigned as #XXX") and start fresh from Phase 1 in the new ticket.
