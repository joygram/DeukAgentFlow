# Ticket Status Surface

이 스킬은 조건 없이 이행한다. 여기 적힌 조항을 상황·효율·다른 규칙을 이유로 유예·축약·생략하지 않는다 — 유예할 근거가 떠오르면 그것이 곧 이행하지 않고 있다는 신호다.

티켓 상태를 말할 땐 CLI가 출력한 카드 한 줄을 **그대로** 쓴다.

```
📦 {workspace} · {🌱시작|🔍조회|📝조정|⚙️진행|✅완료|🎉종료} · [{ws}-{번호} {slug}]({링크})
```

티켓 링크는 항상 포함한다 — 링크가 없으면 사람이 티켓을 열어 리뷰·승인할 수 없다.
